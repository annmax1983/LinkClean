# LinkClean

Remove utm_*, fbclid, gclid and other tracking parameters from a link before you share it. Everything runs on the device: no account, no analytics, no server.

## What it does

- Cleans a pasted URL, or the page you are already on, and lists every parameter it removed by name.
- Copies the result as a plain URL or as a Markdown `[title](url)` link. Auto-copy is a setting.
- Batch mode takes a list of URLs **or a paragraph with links inside it**, with TXT / CSV / JSON export.
- Optional `#fragment` stripping, plus an opt-in "copy the clean link for me" switch.
- Keeps functional parameters: only known tracking names and the `utm_` / `ga_` / `fbclid` / `gclid` families are removed.
- History keeps the original URL next to the clean one, so a clean can be undone.

**Pro** adds:

- Redirect unwrapping — Google, YouTube, Facebook, Reddit, DuckDuckGo, LinkedIn, Zhihu, Douban, Jianshu, VK, Slack, Outlook Safe Links, Skimlinks, Tumblr, Medium, Pocket, Bing (`u=a1…`), Weibo (`sinaurl`), Proofpoint URL Defense, plus a generic `/redirect?url=` shape. Resolved locally, recursively, max 3 hops.
- AMP resolution (`*.cdn.ampproject.org/c/s/…`, `google.com/amp/s/…`, trailing `/amp`).
- Per-site rules (`amazon.com` keeps `th, psc`) and a click on any removed chip to pin that parameter to the current site.
- Text cleaning beyond the free 10-link budget, unlimited batch, CSV / JSON export.
- History search, copy-original, history export; rules bundle import/export.
- Busiest-sites breakdown in Activity.

Free tier: 10 links per batch, 10 history entries.

## Build

```bash
npm install
npm run locales     # regenerate the six _locales files from tools/make-locales.js
npm run icons       # bake icons/ + assets/icon-master.png
npm run build       # minify and write publish/linkclean-v<version>.zip
npm test            # 51 assertions: cleaning, unwrap, site rules, text mode, i18n, popup wiring, manifest
```

`npm run icons:preview` writes `assets/icon-preview.png` (three glyph candidates at 220/64/48/32/16) without touching `icons/`.

> This repository is for project presentation; the complete source is not published. Install LinkClean from the official browser stores.

## Store screenshots

```bash
node tools/shoot.js
```

Writes five 1280×800 shots (the size Chrome Web Store and Edge Add-ons require) plus `promo.png` at 1400×560. Each shot is the real popup, with `chrome.*` answered by `tools/harness/mock-chrome.js`, rendered inside `tools/harness/stage.html` next to a caption. The extension itself is not loaded — Chrome 137+ refuses `--load-extension` from the command line. `promo.html` draws the 1400×560 tile; the 440×280 variant is derived from it separately.

## Pages

`index.html` and `privacy-policy.html` are the landing and privacy pages shipped with the store listing. Both carry their own six-language `MODEL` and a fixed renderer; edit the MODEL, not the markup. `promo.html` is the 1400×560 promotional tile.

## Repo split

This repository builds the Chrome/Edge package (`background.service_worker`). The Firefox twin lives in `codeup/LinkClean` and differs only in `manifest.json` (event page instead of a worker), the `chrome.*` → `browser.*` namespace, and the packaging script. HTML and README stay in this repo only.

## Layout

```
common.js          pure logic: parsing, rule matching, stripTracking, wrapper/AMP unwrap,
                   site rules, text mode, history, stats, CSV/JSON (unit-tested, no chrome.*)
background.js      settings + history + counters storage, licence cache
license.js         Creem licence activation (shared family module)
popup/             the real UI (popup.html / popup.css / popup.js)
_locales/          en, zh_CN, ja, de, es, fr — generated by tools/make-locales.js
icons/             generated by tools/make-icons.js
index.html         landing page, six languages (MODEL + renderer)
privacy-policy.html privacy page, six languages
promo.html         1400×560 store tile
languages/         README_de / es / fr / ja / zh
store-listing/     per-language listing text, CRLF, no browser names except Microsoft Edge
tools/harness/     chrome.* mock and the 1280×800 stage used by tools/shoot.js
test/              node --test suites
```
