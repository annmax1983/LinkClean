# LinkClean - リンククリーナー

[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

共有する前に、リンクから追跡の尾を落とす。URL を貼り付けると、削除したパラメータを一つずつ示し、リダイレクトと AMP を展開して、きれいなリンクを返します。処理はすべて端末内で完結し、リンクがブラウザの外に出ることはありません。

## ハイライト

- **貼り付け一回で、きれいなリンク一本** —— URL を貼るか、いま開いているタブをそのまま取り込みます。
- **何を消したかが分かる** —— 削除したパラメータは名前ごとに一覧表示され、サイトに渡るはずだった値も見られます。黙って書き換えることはありません。
- **プレーン URL でも Markdown でもコピー** —— Markdown は実際のページタイトルから `[タイトル](URL)` を組み立てます。
- **バッチモード** —— 「1 行 1 URL」だけでなく、段落・メール・チャットログも受け付けます。書き換えるのは中のリンクだけで、前後の文章はそのまま残ります。
- **機能パラメータは残す** —— 削除するのは既知の追跡パラメータ名 61 個と、プレフィックス系列 12 個（`utm_`、`ga_`、`mtm_`、`piwik_`、`_hs` など）だけです。
- **Pro：リダイレクトの展開** —— Google、YouTube、Facebook、Reddit、DuckDuckGo、LinkedIn、知乎、豆瓣、簡書、少数派、VK、Slack、Outlook Safe Links、Skimlinks、Tumblr、Medium、Pocket に加え、Bing、Weibo、Proofpoint、汎用の `/redirect?url=`。最大 3 ホップまで端末内で再帰解析します。
- **Pro：AMP の展開** —— `cdn.ampproject.org/c/s/`、`google.com/amp/s/`、末尾の `/amp` は正規ページに戻ります。
- **Pro：サイト別ルール** —— `amazon.com` だけ `th` と `psc` を残し、それ以外は削除。より具体的なドメインが優先され、サブドメインは継承します。結果の削除済みパラメータをクリックすると、そのサイトの保留リストに永久追加されます。
- **Pro：履歴とカウンター** —— リンク・タイトル・ドメインで履歴を検索、元リンクをコピー、JSON 書き出し。クリーニングしたリンク数と削除したパラメータ数も記録します。

## 使い方

1. LinkClean のアイコンをクリックします。現在のページに追跡パラメータがあれば、入力欄はすでに埋まっています。
2. 「リンクをきれいにする」を押します。結果にはきれいな URL、削除されたパラメータのチップ、ライセンスがあってリダイレクトに当たった場合は展開した連鎖が表示されます。
3. リンクをコピーする、Markdown としてコピーする、開く、または同じリンクをバッチに回します。
4. 「これは消したくない」と思ったパラメータは、結果の中でクリックすればそのサイトの保留リストに入ります。

## プライバシー

- リンクはブラウザの外に出ません。すべてのルールは端末内の文字列処理で、**リンク先を知るためにリダイレクトを実際に取得することはありません**。
- 解析もテレメトリも広告識別子も追跡ピクセルもありません。
- 履歴・設定・カウンターは `chrome.storage.local` に保存され、いつでも消去できます。
- ネットワーク通信は Pro ライセンスの有効化・確認のみ：キー、ランダムなインストール識別子、プラグイン id、基本的なブラウザ情報。
- クリップボードを読むのは「貼り付け」を押したときだけ、書き込むのはコピーまたは自動コピーが有効なときだけです。

## 権限について

| 権限 | 用途 |
|---|---|
| `storage` | 設定、カスタムルール、履歴、ライセンス状態を端末内に保存 |
| `activeTab` | アイコンをクリックした後に限り、現在のページの URL を読む |
| `clipboardWrite` | コピー操作や自動コピー時にきれいなリンクを書き込む |
| `clipboardRead` | 「貼り付け」を押したときだけクリップボードを読む（バックグラウンドでは読まない） |
| `https://api.annmax1983.com/*` | ライセンスの有効化と確認のみ。リンクは送信しません |

コンテンツスクリプトはなく、`<all_urls>` のホスト権限も、`tabs` 権限も、`downloads` 権限もありません。LinkClean はどのページの本文も見られません。

## 対応ブラウザ

Chrome と Edge（Manifest V3、Chrome 116 以降）。Firefox 版は計画中です。

## 開発

```bash
npm install        # 開発依存のみ：terser
npm run locales    # tools/make-locales.js から 6 言語の _locales を生成
npm run icons      # アイコンを生成
npm test           # node --test：クリーニング、リダイレクト、サイト別ルール、i18n、ポップアップ配線
npm run build      # 圧縮 + パッケージ → publish/linkclean-v{version}.zip
node tools/shoot.js  # 実 Chrome で 1280×800 のストア用スクリーンショットと promo 画像を生成
```
